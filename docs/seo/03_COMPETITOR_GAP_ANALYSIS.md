# 03 — Competitor and SERP Gap Analysis

**Date:** 2026-11-17

## Method and limits

- SERPs were sampled with a web-search tool for: "security services in Pune security agency guards", "industrial security services Pune factory security guards agency" and "housekeeping services in Pune for office commercial housekeeping company". Earlier SERP and autocomplete evidence is in `seo-audit/SEO_AUDIT_NOV_2026.md`, `docs/seo-competitor-analysis.md` and `seo-audit/data/`.
- **The search tool is US-based**, so result order does **not** represent Google.co.in rankings for a Pune searcher. Treat the competitor set as *who is visible*, not *who ranks #1*.
- **No backlink data** was available (no Ahrefs/Semrush/Moz access). No backlink figures are stated.
- Competitor claims (years in business, prices, licences) are their own marketing and were **not** verified.

### B. Missing content topics (now covered)
- What a security agency provides; how many guards a property needs (worked method, no invented ratios); responsibilities of security personnel; what to check before hiring → security pillar and guide.
- Gate-pass, material-gate, contractor-labour and shift-changeover procedures → industrial page.
- Visitor management, after-hours patrols and single-occupier vs multi-tenant set-up → corporate page.
- Principal-employer PF/ESIC liability → industrial page and guide.
- Managed contract vs manpower supply; housekeeping vs facility management → housekeeping pillar.
