# How to use the KARGAR External SEO workbook

**File:** `KARGAR_External_SEO_Backlink_and_Business_Listing_Report.xlsx`
**Research date:** 19-Nov-2026
**Scope:** Off-page work only: listings, citations, backlinks and brand mentions. The website was not changed and nothing was submitted or registered.

## Who this is for

KARGAR senior management and whoever is doing the listing and outreach work. You don't need SEO knowledge to use it.

## How to read the columns

- **Priority:** HIGH means relevant, credible and realistic, so do it. MEDIUM means it's useful but needs checking first. LOW means limited value, so do it only if time allows. REJECT means don't use it (broken, spam or irrelevant).
- **Verification Status:**
  - *Verified*: we visited the page during research and confirmed it.
  - *Partially verified*: part of it was confirmed, such as the sign-up link but not the price.
  - *Verified absent*: we checked, and KARGAR is not listed.
  - *Manual verification required*: the site blocks automated visits (for example LinkedIn, Facebook or Justdial), so someone must open it in a browser.
  - *Not verified*: a real website whose opportunity we have not confirmed. Check it before you spend time on it.
- **Cost and Link Type:** "Not verified" or "Unknown" means we could not confirm it. We never assumed a listing is free or that a link is dofollow.
- **Target Page:** the KARGAR page that the listing or link should point to.

## How to use it day to day

1. **Start with sheet 08.** Management should approve one official name, address, phone and email, and the exact registered legal name with its CIN. Every listing must use exactly these details.
2. **Work through sheet 10, week by week.** Fill in the shaded cells: Owner, Status (drop-down), Due Date, Date Completed, Live URL and notes. The first row shows an example owner. Replace it.
3. **Update the status column on sheets 02 to 06** when you create, claim or correct a listing (shaded "Registration Status" / "Outreach Status" column).
4. **Paste the live URL** into sheet 10 once a listing or link is published. Only then does it count as acquired.
5. **Sheet 01 updates itself.** Its counts are formulas that read the other sheets. If you add rows, extend the formula ranges, or add rows *inside* the existing table.

## Important limitations

- No paid SEO tools (Ahrefs, Semrush, Moz, DataForSEO) or Google Search Console were connected. That means there are **no Domain Authority, Domain Rating or traffic numbers**, and sheet 07 is a competitor *citation* gap rather than a full backlink-profile comparison. Connecting Moz's free API or a paid tool would let you upgrade sheet 07.
- Google Business Profile status can't be confirmed from outside. Only the account owner can check it.
- No listing or link guarantees a ranking improvement. These actions build trust and visibility over time.

## Rules for the team (do not break)

- Don't buy bulk backlink packages or pay for links to raise a score.
- Don't create fake reviews, profiles or relationships.
- Don't submit to sites marked REJECT.
- Don't change official business information without management approval.
