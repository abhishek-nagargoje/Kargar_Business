# 90-Day Link-Building Plan

No fixed backlink-count promises are made anywhere in this plan (per Phase 17/24 of the brief). Success is measured in quality referring domains, relevance, and ranking/traffic movement — tracked in `kargar-authority-dashboard.md`.

## Month 1 — Foundation (data + relationships)

- [ ] **Get real data access** (highest priority, blocks everything else): free Moz API key, free Bing Webmaster verification, free Google Search Console verification. This alone unlocks 80% of the phases in the master brief that currently read "unavailable."
- [ ] Re-run the backlink audit once Moz/GSC exist — get real DA/DR/UR, real ranking position for "housekeeping services Pune," real impressions/clicks
- [ ] Internally confirm the `logo-manifest.json` client list (§2 of `link-building-strategy.md`) with whoever owns those accounts — identify which 3-5 relationships are warmest to approach first
- [ ] Join MCCIA and/or DCCIA Pune as a member (real business decision, not a link-building tactic — the membership listing is a side benefit of genuine participation)
- [ ] Confirm ownership/status of `kargar.co.in` (see `toxic-link-review.md`)
- [ ] Add real LinkedIn/Facebook profile URLs to `Organization` schema `sameAs` array — code change, needs approval (ties to existing finding in `SEO_AUDIT_REPORT.md` §4.4/§6.3)
- [ ] Draft (don't build) the Office Housekeeping SOP/Checklist linkable asset outline

## Month 2 — Outreach + first asset

- [ ] Approach 2-3 warmest client relationships for a vendor-page mention or short case study (using `outreach-templates.md` §A)
- [ ] Publish the Office Housekeeping SOP/Checklist if content quality bar is met
- [ ] Identify 2-3 genuine local Pune business-publication or industry-publication digital-PR angles (facility management trends, workplace hygiene standards) and pitch with a named Kargar expert
- [ ] Re-check competitor domains identified in `backlink-audit.md` §5 with real Moz/DataForSEO data now available — build the actual gap table

## Month 3 — Compound + review

- [ ] Follow up on Month 2 outreach; convert warm leads into published mentions
- [ ] Case study from any client relationship that agreed
- [ ] Backlink quality review using real data (toxic link review, now populated with actual figures)
- [ ] Ranking/performance review: GSC position/impressions/clicks for "housekeeping services Pune" and variants, before/after comparison
- [ ] Decide on a second linkable asset only if the first showed real link/traffic response

## Explicitly out of scope for all 90 days (per non-negotiable rules)

Purchased links, automated software, directory mass-submission, PBNs, link farms, fake profiles/reviews, comment/forum spam, guest-post networks, disavowing anything without evidence, any outreach sent without your explicit approval.
