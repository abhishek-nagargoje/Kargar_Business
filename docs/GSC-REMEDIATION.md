## GSC actions required from you (cannot be done from this codebase)

1. **Submit the sitemap** in Search Console (Sitemaps → add `https://www.kargarbusinessservices.com/sitemap.xml`) if not already submitted, so Google picks up the internal-linking changes faster.
2. **URL Inspection → Request Indexing** for `/services/hard-services`, `/services/hard-services/hvac-maintenance`, and `/services/soft-services/security-services` specifically — these three had the internal-link-depth fix and would benefit from a manual recrawl nudge rather than waiting for organic recrawl.
3. **Do not** request indexing for `/category/services/`, `/services/`, `/sectors/`, or `/privacy-policy/` (trailing-slash variants) — those are intentionally redirecting; requesting indexing on a redirecting URL has no effect and just adds noise.
4. **Wait, don't chase to zero.** Per the brief's own Phase 30 rule: none of the "Excluded" reasons above indicate a bug. Re-validating in GSC before Google actually recrawls will just show the same stale state — validation takes real time.
5. **Separately, a required Vercel action** (not a GSC action, but blocks the brand-consistency fix from taking effect — see `LIVE-SEO-AUDIT.md` §1 for full detail): update the `VITE_SITE_NAME` environment variable in the Vercel project settings from `Kargar Facility Management` to `KARGAR Facility Management`, then trigger a redeploy. This env var is not in the git repo (correctly gitignored, since it's project config) and cannot be changed from a code commit.
